# Codex 1 分钟快速配置

<Callout type="info">
**这页是给完全没用过终端的同学准备的。** 全程只需要：① 下载一个软件 ② 复制粘贴 Key 和两段配置 ③ 在终端复制粘贴一行命令（**仅此一行**）。  
看完跟着做，1 分钟能让 Codex 跑起来。
</Callout>

<Callout type="warning">
**Codex 比 Claude Code 多一步 "终端命令"。** 这一步只是复制粘贴一行，但绕不开 —— Codex 的认证机制要求 API Key 必须从系统环境变量里读取。已经习惯命令行的可以直接跳到 [第 3 步](#第-3-步-配置环境变量-必做)。
</Callout>

---

## 你需要准备的两样东西

<Steps>

### 一台 Windows 或 Mac 电脑

Windows 10/11 或 macOS 都可以。

### 一个 CC Club API Key

如果还没有，先去 [获取 API Key](/getting-started/claude-code/get-api-key) 免费申请一把（领完回到这页继续）。

API Key 形如 `cr_xxxxxxxxxxxxxxxxxxxxxxxxxxxx`，**先复制到一个记事本里**，等下要用 **3 次**（GUI 表单、auth.json、终端环境变量）。

</Steps>

## 第 1 步：下载并安装 CC Switch

CC Switch 是一个**桌面应用**，帮你管理 API 配置 —— 全程只需复制粘贴，无脑操作。

<Tabs items={['Windows', 'macOS']}>
  <Tabs.Tab>

    1. 点击下载：[CC Switch Windows 版 (.msi, 12 MB)](https://github.com/farion1231/cc-switch/releases/download/v3.15.0/CC-Switch-v3.15.0-Windows.msi)
    2. 双击下载好的 `.exe`，按提示完成安装
    3. 安装完成后，从开始菜单打开 **CC Switch**

    <Callout type="warning">
    第一次打开如果 Windows 弹出 "Windows 已保护你的电脑"，点 **"更多信息" → "仍要运行"**。
    </Callout>

  </Tabs.Tab>
  <Tabs.Tab>

    1. 点击下载：[CC Switch macOS 版 (.dmg, 26 MB)](https://github.com/farion1231/cc-switch/releases/download/v3.15.0/CC-Switch-v3.15.0-macOS.dmg)
    2. 双击下载好的 `.dmg`，把 **CC Switch** 图标拖到 **Applications** 文件夹
    3. 从启动台（Launchpad）打开 **CC Switch**

    <Callout type="warning">
    第一次打开如果 macOS 提示 "无法打开"，去 **系统设置 → 隐私与安全性**，下拉到最下方点 **"仍要打开"**。
    </Callout>

  </Tabs.Tab>
</Tabs>

## 第 2 步：在 CC Switch 里填一份配置

打开 CC Switch 后，照下面动作做：

<Steps>

### 切到 Codex 分组

CC Switch 左侧有一列分组：**Claude / Claude Desktop / Codex / OpenCode / Gemini**。点 **Codex**。

### 点 "+ 添加供应商"

页面右上角的蓝色按钮。会弹出一个表单。

### 按下表填 GUI 字段

| 字段 | 填什么 |
|------|--------|
| 供应商名称 | 随便取，比如 `CC Club Codex` |
| 官网链接 | **留空** |
| API | 把你的 Key 贴进来 |
| 请求地址 | `https://claude-code.club/openai` |
| API 格式 | 下拉选 **OpenAI Chat Completions** |
| 模型区域 | **留空** |

### 在 "auth.json 配置" 框里贴这段

把整段贴进去，**只改一个地方**：把 `OPENAI_API_KEY` 后面那对空引号 `""` 里填上你的 API Key。

```json
{
  "OPENAI_API_KEY": "你的 API 密钥"
}
```

### 在 "config.toml 配置" 框里贴这段

整段贴进去，**不用改任何内容**：

```toml
model_provider = "club"
model = "gpt-5.4"
model_reasoning_effort = "medium"
disable_response_storage = true
preferred_auth_method = "apikey"

[model_providers.club]
name = "ai code club"
base_url = "https://claude-code.club/openai"
wire_api = "responses"
requires_openai_auth = true
env_key = "OPENAI_API_KEY"

[features]
shell_snapshot = true
multi_agent = true
unified_exec = true
```

成功会回到列表，看到一条新的 `CC Club Codex` 供应商。

</Callout>

</Steps>

## 第 3 步：配置环境变量（必做）

**这是 Codex 和 Claude Code 最大的不同。** Codex 启动时会去**系统环境变量**里找 `OPENAI_API_KEY`，CC Switch 的 GUI 里的 Key 不会自动注入到这里。所以我们需要复制粘贴**一行命令**到终端。

<Tabs items={['Windows', 'macOS']}>
  <Tabs.Tab>

打开 **PowerShell**（开始菜单搜 "powershell"），把下面这行**整段复制**，**把 `cr_xxxxxxxxxx` 替换成你自己的 API Key**，回车：

```powershell
[System.Environment]::SetEnvironmentVariable('OPENAI_API_KEY', 'cr_xxxxxxxxxx', 'User')
```

<Callout type="info">
**这条命令做了什么？** 把 `OPENAI_API_KEY` 写到 Windows 用户级环境变量里，永久生效。设完后 **重启 PowerShell** 才能让新启动的进程读到。
</Callout>

  </Tabs.Tab>
  <Tabs.Tab>

打开**终端 (Terminal)**（启动台搜 "终端"），把下面这行**整段复制**，**把 `cr_xxxxxxxxxx` 替换成你自己的 API Key**，回车：

```bash
echo 'export OPENAI_API_KEY="cr_xxxxxxxxxx"' >> ~/.zshrc && source ~/.zshrc
```

<Callout type="info">
**这条命令做了什么？** 把 `export OPENAI_API_KEY=...` 写到你的 shell 启动配置 `~/.zshrc` 里，永久生效。`source` 让当前终端立即读取这个配置。
</Callout>

  </Tabs.Tab>
</Tabs>

<Steps>

### 先点 "测试" 验证配置

在刚保存的那条 `CC Club Codex` 供应商行上，点蓝色 **测试** 按钮（如上方图 ①）。CC Switch 会用你填的 Key + 请求地址向上游发一次握手请求。

- ✅ **看到绿色 "测试成功" 提示**（图 ②）：Key 和地址都对，可以继续下一步
- ❌ **看到红色错误**：通常是 Key 错了 / 地址错了 / 网络不通。点 **编辑** 检查 `OPENAI_API_KEY` 和 `base_url`，最常见的坑是 **Key 首尾带了空格**

<Callout type="info">
**为什么先测试？** 测试只验证"CC Switch 能连上 API"，不需要 Codex 本体。先把这一步走通，等下装命令行才有底。
</Callout>

### 点 "启用" 激活这条配置

测试通过后，点同一行的绿色 **启用** 按钮（图 ③）。激活成功后：

- 行首会出现一个 **✓ 勾选标记**
- 状态从"已保存"变成"**当前使用**"

<Callout type="warning">
**保存 ≠ 启用 ≠ 测试**，三件事各走各的：
- **保存** = 把这条配置写进 CC Switch
- **测试** = 检查这条配置能不能连通
- **启用** = 让 Codex 实际用这条配置

不点"启用"，就算测试通过也不生效。
</Callout>

### 装 Codex CLI

CC Switch 只管"配置"，不管"安装"。Codex 本体还得装一次 ——
在 CC Switch 顶部找 **"安装 Codex"** 按钮，点一下，它会自动帮你装好。

（如果找不到按钮、或者按钮报错，按 [手动安装步骤](#手动安装-codex) 走。）

### 在终端验证一次

```bash
codex "用一句话解释什么是 vibe coding"
```

几秒内返回一段中文（如上方图 ④），**整条链路就通了** 🎉。

</Steps>

## 出问题了？

<details>
<summary>**问题 1：终端输 `codex` 提示 "找不到命令"**</summary>

说明 Codex CLI 本体没装好。两个办法：

- **重试 CC Switch 的"安装 Codex"按钮**：可能上一次因为网络中断没装完
- **换手动安装**：跟着 [手动安装步骤](#手动安装-codex)（下面）走
</details>

<details>
<summary>**问题 2：跑 `codex` 报 "Invalid API key" 或 "Authentication failed"**</summary>

99% 是**第 3 步没做或没生效**。三个检查：

1. **重启终端**：环境变量设置后必须**重开**一个新终端窗口，旧窗口读不到
2. **验证环境变量已设置**：
   - Windows PowerShell：`echo $env:OPENAI_API_KEY`
   - macOS Terminal：`echo $OPENAI_API_KEY`
   - 应该输出你的 Key；如果是空的，第 3 步没生效，重做一遍
3. **确认 CC Switch 里供应商已激活**：列表中那条 `CC Club Codex` 前面要有 ✓ 勾选标记
</details>

<details>
<summary>**问题 3：响应很慢 / 一直转圈**</summary>

可能是网络节点不合适。回 CC Switch 编辑那条供应商，把 `请求地址` 和 `config.toml` 里的 `base_url` **同时改成**下面其中一组再保存：

- `https://jp.claude-code.club/openai` — 日本节点（回国优化）
- `https://hk.claude-code.club/openai` — 香港节点（回国优化）
- `https://sz.ai-code.club/openai` — 深圳节点（国内中转出境）

改完别忘了再单击一次激活。
</details>

<details>
<summary id="手动安装-codex">**手动安装 Codex（备用方案）**</summary>

如果 CC Switch 里没有"安装 Codex"按钮，或者点了报错，手动装一次。

需要先有 Node.js（v18+）：

```bash
npm install -g @openai/codex
```

或者 macOS 上用 Homebrew：

```bash
brew install --cask codex
```

装完回这页继续做"第 3 步"。
</details>
