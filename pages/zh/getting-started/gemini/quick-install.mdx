# Gemini 1 分钟快速配置

<Callout type="info">
**这页是给完全没用过终端的同学准备的。** 全程只需要：① 下载一个软件 ② 复制粘贴 Key ③ 点一下"激活"。  
看完跟着做，1 分钟能让 Gemini 跑起来。
</Callout>

---

## 你需要准备的两样东西

<Steps>

### 一台 Windows 或 Mac 电脑

Windows 10/11 或 macOS 都可以。

### 一个 CC Club API Key

如果还没有，先去 [获取 API Key](/getting-started/claude-code/get-api-key) 免费申请一把（领完回到这页继续）。

API Key 形如 `cr_xxxxxxxxxxxxxxxxxxxxxxxxxxxx`，**先复制到一个记事本里**，等下要用。

</Steps>

---

## 第 1 步：下载并安装 CC Switch

CC Switch 是一个**桌面应用**，帮你管理 API 配置 —— 全程只需复制粘贴，无脑操作。

<Tabs items={['Windows', 'macOS']}>
  <Tabs.Tab>

    1. 点击下载：[CC Switch Windows 版 (.msi, 12 MB)](https://github.com/farion1231/cc-switch/releases/download/v3.15.0/CC-Switch-v3.15.0-Windows.msi)
    2. 双击下载好的安装包，按提示完成安装
    3. 安装完成后，从开始菜单打开 **CC Switch**

    <Callout type="warning">
    第一次打开如果 Windows 弹出 "Windows 已保护你的电脑"，点 **"更多信息" → "仍要运行"**。
    </Callout>

  </Tabs.Tab>
  <Tabs.Tab>

    1. 点击下载：[CC Switch macOS 版 (.dmg, 26 MB)](https://github.com/farion1231/cc-switch/releases/download/v3.15.0/CC-Switch-v3.15.0-macOS.dmg)
    2. 双击下载好的 `.dmg`，把 **CC Switch** 图标拖到 **Applications** 文件夹
    3. 从启动台（Launchpad）打开 **CC Switch**

    <Callout type="warning">
    第一次打开如果 macOS 提示 "无法打开"，去 **系统设置 → 隐私与安全性**，下拉到最下方点 **"仍要打开"**。
    </Callout>

  </Tabs.Tab>
</Tabs>

## 第 2 步：在 CC Switch 里填一份配置

打开 CC Switch 后，照下面动作做：

<Steps>

### 切到 Gemini 分组

CC Switch 左侧有一列分组：**Claude / Claude Desktop / Codex / OpenCode / Gemini**。点 **Gemini**。

### 点 "+ 添加供应商"

页面右上角的蓝色按钮。会弹出一个表单。

### 只填两个字段就够了

| 字段 | 填什么 |
|------|--------|
| 供应商名称 | 随便取，比如 `CC Club Gemini` |
| API | 把你的 CC Club API Key 贴进来 |
| 请求地址 | `https://claude-code.club/gemini` |

其他字段（配置 JSON、模型区域等）**全部留空**——Gemini 走最简模式，只需要 Key 和请求地址就能跑。

<figure style={{ margin: '0.75rem 0 0', padding: '0.6rem', background: 'rgba(251, 146, 60, 0.05)', border: '1px solid rgba(251, 146, 60, 0.2)', borderRadius: '8px' }}>

    ↑ 填完后大概长这样：<strong>API Key</strong> 一行小圆点 + <strong>请求地址</strong> 是 <code style={{ background: 'rgba(0,0,0,0.04)', padding: '1px 6px', borderRadius: '4px' }}>https://claude-code.club/gemini</code>

<Callout type="info">
**为什么 Gemini 比 Claude/Codex 简单？** Gemini CLI 默认只读两个值：API Key 和 Base URL。CC Switch 把这两个填上、激活，就能直接用，不需要额外的 JSON/TOML 配置块。
</Callout>

### 点右下角 "保存"

成功会回到列表，看到一条新的 `CC Club Gemini` 供应商。

</Steps>

<Steps>

### 先点 "测试" 验证配置

在刚保存的那条 `CC Club Gemini` 供应商行上，点蓝色 **测试** 按钮（如上方图 ①）。CC Switch 会用你填的 Key + 请求地址向上游发一次握手请求。

- ✅ **看到绿色 "测试成功" 提示**（图 ②）：Key 和地址都对，可以继续下一步
- ❌ **看到红色错误**：通常是 Key 错了 / 地址错了 / 网络不通。点 **编辑** 检查 API Key 和请求地址，最常见的坑是 **Key 首尾带了空格**

<Callout type="info">
**为什么先测试？** 测试只验证"CC Switch 能连上 API"，不需要 Gemini CLI 本体。先把这一步走通，等下装命令行才有底。
</Callout>

### 点 "启用" 激活这条配置

测试通过后，点同一行的绿色 **启用** 按钮（图 ③）。激活成功后：

- 行首会出现一个 **✓ 勾选标记**
- 状态从"已保存"变成"**当前使用**"

<Callout type="warning">
**保存 ≠ 启用 ≠ 测试**，三件事各走各的：
- **保存** = 把这条配置写进 CC Switch
- **测试** = 检查这条配置能不能连通
- **启用** = 让 Gemini CLI 实际用这条配置

不点"启用"，就算测试通过也不生效。
</Callout>

### 装 Gemini CLI 本体

CC Switch 只管"配置"，不管"安装"。Gemini CLI 本体还得装一次 ——
在 CC Switch 顶部找 **"安装 Gemini CLI"** 按钮，点一下，它会自动帮你装好。

（如果找不到按钮、或者按钮报错，按 [手动安装步骤](#手动安装-gemini-cli) 走。）

### 在终端验证一次

```bash
gemini
```

首次运行会询问认证方式，选择 **`2. Use Gemini API Key`**。它会自动读取 CC Switch 写好的 Key 和地址，几秒后进入交互界面（如上方图 ④），**整条链路就通了** 🎉。

</Steps>

## 出问题了？

<details>
<summary>**问题 1：终端输 `gemini` 提示 "找不到命令"**</summary>

说明 Gemini CLI 本体没装好。两个办法：

- **重试 CC Switch 的"安装 Gemini CLI"按钮**：可能上一次因为网络中断没装完
- **换手动安装**：跟着 [手动安装步骤](#手动安装-gemini-cli)（下面）走
</details>

<details>
<summary>**问题 2：Gemini 启动报 "Authentication failed" 或反复要求登录**</summary>

如果 CC Switch 那条供应商**已经激活**（前面有 ✓）但 Gemini 仍然无法认证，多半是因为环境变量没有自动注入。手动设一次：

<Tabs items={['Windows', 'macOS / Linux']}>
  <Tabs.Tab>

打开 **PowerShell**，把下面两行整段复制，**把 `cr_xxxxxxxxxx` 替换成你的 API Key**，回车：

```powershell
[System.Environment]::SetEnvironmentVariable('GEMINI_API_KEY', 'cr_xxxxxxxxxx', 'User')
[System.Environment]::SetEnvironmentVariable('GOOGLE_GEMINI_BASE_URL', 'https://claude-code.club/gemini', 'User')
```

设完后**重启 PowerShell** 才能让新进程读到。

  </Tabs.Tab>
  <Tabs.Tab>

打开**终端**，把下面这段整段复制，**把 `cr_xxxxxxxxxx` 替换成你的 API Key**，回车：

```bash
echo 'export GEMINI_API_KEY="cr_xxxxxxxxxx"' >> ~/.zshrc
echo 'export GOOGLE_GEMINI_BASE_URL="https://claude-code.club/gemini"' >> ~/.zshrc
source ~/.zshrc
```

  </Tabs.Tab>
</Tabs>

设完后重新跑 `gemini`。
</details>

<details>
<summary>**问题 3：响应很慢 / 一直转圈**</summary>

可能是网络节点不合适。回 CC Switch 编辑那条供应商，把 `请求地址` 改成下面其中一个再保存：

- `https://jp.claude-code.club/gemini` — 日本节点（回国优化）
- `https://hk.claude-code.club/gemini` — 香港节点（回国优化）
- `https://sz.ai-code.club/gemini` — 深圳节点（国内中转出境）

改完别忘了再单击一次激活。
</details>

<details>
<summary id="手动安装-gemini-cli">**手动安装 Gemini CLI（备用方案）**</summary>

如果 CC Switch 里没有"安装 Gemini CLI"按钮，或者点了报错，手动装一次。

需要先有 Node.js（v18+）：

```bash
npm install -g @google/gemini-cli
```

装完回这页继续做"第 3 步"。
</details>
