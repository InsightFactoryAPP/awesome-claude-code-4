# Ask About Claude's Capabilities

Claude has built-in access to its documentation and can answer questions about its own features and limitations.

## Example Questions

```
> can Claude Code create pull requests?
```

```
> how does Claude Code handle permissions?
```

```
> what slash commands are available?
```

```
> how do I use MCP with Claude Code?
```

```
> how do I configure Claude Code for Amazon Bedrock?
```

```
> what are the limitations of Claude Code?
```

<Callout>
Claude provides documentation-based answers to these questions. For executable examples and hands-on demonstrations, refer to the specific workflow sections above.
</Callout>

<Callout type="info">
**Tips:**

* Claude always has access to the latest Claude Code documentation, regardless of which version you are using
* Ask specific questions to get detailed answers
* Claude can explain complex features such as MCP integration, enterprise configuration, and advanced workflows
</Callout>
