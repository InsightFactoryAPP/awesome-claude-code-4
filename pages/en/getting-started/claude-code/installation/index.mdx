# Installation and Configuration

<Callout type="info">
**Before you begin:**  
1. Make sure you have already obtained an [API Key](/getting-started/get-api-key)
2. Make sure your network can access common international software sites such as: github.com, nodejs.org, nodesource.com, brew.sh, etc.
</Callout>

Getting started with Claude Code is simple! We provide detailed installation guides for every operating system.

Each installation guide offers two installation methods:
  - **One-click script installation**: Fully automated, great for beginners, completes in 5 minutes
  - **Manual installation**: Full control over the installation process, suited for experienced users
