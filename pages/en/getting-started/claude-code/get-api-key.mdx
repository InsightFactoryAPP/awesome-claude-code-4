## How to Apply

<Steps>
### Create an Account

Visit the official site: https://claude-code.club

Click the "Login" button in the top-right corner and complete registration.

### Create an API Key

1. After logging into the CC Club self-service portal, click "Key Management" in the left sidebar.
2. Click the "Create API Key" button in the top-right corner.
3. Save your API key securely.
